# World Cup 2026 — Data Analysis

🚧 **Work in progress.** This portfolio project tests specific football theses about the 2026 World Cup
against data — Spain's historically dominant defensive campaign, the two contrasting paths Spain and
Argentina took to the final, and whether the final's shot volume was consistent with how it was decided.

Full write-up, architecture, and live demo link will be added here as the project reaches its first working
modules. See `CLAUDE.md` for current scope and status.
